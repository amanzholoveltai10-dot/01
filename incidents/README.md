# Журнал инцидентов

Заполняется начиная с модуля 1. Один инцидент — один файл `YYYY-MM-DD-short-name.md`:

```markdown
# Краткое название

## Симптом
Что видел пользователь / что не работало.

## Что в логе
Реальные строки лога.

## Причина
Почему это произошло.

## Исправление
Что сделал и как проверил, что починилось.

## Как не допустить снова
```
